# Containerized Portfolio Website (Rootless)

My modern, fast, and secure personal portfolio website built with clean engineering principles, modular Nginx Server Side Includes (SSI), and a fully automated DevOps pipeline.

---

## Tech Stack & Architecture

* **Frontend:** Vanilla JavaScript, Modern CSS
* **Template Engine:** Nginx SSI (Server Side Includes) for zero-layout-shift, SEO-friendly component modularity.
* **Web Server:** Nginx (hardened and optimized).
* **DevOps & Infrastructure:** 
  * Docker (Rootless image)
  * GitHub Actions & GitHub Container Registry (GHCR) for CI/CD
  * Renovate Bot for automated base image updates
