Architecture Overview

Infrastructure Breakdown

Hardware Layer

The homelab runs on a multi-node physical cluster orchestrated through Proxmox VE. Infrastructure and configuration are fully managed via GitOps, using Terraform for resource provisioning, Ansible for automated rollouts, and SOPS + age for secure secrets encryption.

Network Topology

Perimeter defense is secured by OPNsense with network-wide DNS adblocking via Pi-hole. External traffic enters through Cloudflare Edge (WAF & country block protection with proxied CNAME records kept in sync by a dedicated DDNS LXC), routed via port forwarding to Nginx Proxy Manager running on the Main node to distribute traffic to internal services. Remote LAN access is provided securely via a Wireguard LXC.

Node Responsibilities

  • Node 1 — Main Node: The Production node, hosting critical services and applications like Reverse Proxy, NAS, Github Actions Runner, Renovate-Cron, Media Server and other Docker stacks.
  • Node 2 — Firewall Node: Dedicated perimeter security running OPNsense VM (NIC passthrough for routing/DHCP) and Pi-hole LXC.
  • Node 3 — Backup Node: Powers on weekly via schedule to sync snapshots from Main TrueNAS via rsync and replicates it via ZFS replication, then automatically powers down.
  • Node 4 — AI Node: GPU compute node running llama.cpp, AI Agent, MCP Servers. This is the Node where all AI magic happens.
